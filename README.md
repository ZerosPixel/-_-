# БУНКЕР — минимальная онлайн-версия

Готовая статическая веб-игра на обычных HTML + CSS + JavaScript. Никакого npm, базы данных или сборки не требуется.

## Что внутри

- 6–15 игроков.
- Два режима: без отдельного ведущего / с ведущим.
- Случайная катастрофа и случайный бункер.
- 11 безопасных категорий характеристик персонажа.
- В 1-м раунде профессия раскрывается автоматически, затем игрок открывает ещё 2 характеристики.
- В каждом следующем раунде количество новых открываемых характеристик соответствует таблице базовых правил.
- 2 минуты общего обсуждения.
- 30 секунд речи каждого игрока перед голосованием.
- 2 минуты живого голосования: можно обсуждать, защищаться и менять свой голос до завершения.
- Когда все проголосовали, ведущий/создатель может завершить голосование раньше таймера.
- 70% порог, оправдание и повторное голосование.
- Каждый кандидат получает оправдательную речь не более одного раза за раунд.
- В первом раунде большинство игроков может выбрать пропуск. Тогда никто не исключается, а в следующем раунде нужно исключить двух игроков.
- Отсутствующий голос считается воздержанием, а не голосом против себя — это сделано для голосового чата, чтобы случайный пропуск клика не ломал игру.
- После исключения предусмотрена 15-секундная прощальная речь.
- После последнего раунда выжившие раскрывают все характеристики.
- Финальная симуляция учитывает катастрофу, бункер, ресурсы, здоровье, навыки, командную работу, покрытие ключевых задач, синергию состава и условную демографическую устойчивость.
- Система синергии использует убывающую отдачу: одинаковые навыки помогают всё меньше, а разные люди, закрывающие разные задачи, ценятся выше.
- Для каждого персонажа есть мягкий потолок влияния на отдельный домен, поэтому один очень удачный набор карт не делает персонажа гарантированным победителем.
- Есть небольшие контекстные бонусы за связки вроде «пища + вода», «техника + тепло», «медицина + командная работа» и за соответствие системам конкретного бункера.

## Баланс относительно базовых правил

Основная структура сохранена: 6–15 игроков, половина мест в бункере с округлением вниз, обязательная профессия в первом раунде, таблица раскрытия характеристик, 30-секундные речи, 70% порог, оправдания, повторные голосования и специальный пропуск только в первом раунде.

Адаптированы только вещи, которые особенно неудобны в голосовом чате:

1. Общее обсуждение — 120 секунд вместо 60.
2. Голосование — 120 секунд вместо 15.
3. Во время голосования нет обязательной тишины: игроки могут обсуждать и менять мнение.
4. Голос можно менять до завершения голосования.
5. Отсутствующий голос не считается голосом против самого игрока.
6. Неполное открытие карточек в один раунд не блокирует последующие раунды: счётчик открытия идёт по каждому раунду отдельно.
7. Нераскрытые карточки выбывшего игрока не показываются остальным. Полный набор раскрывается только у тех, кто попал в бункер.
8. В финальном расчёте учитываются все характеристики выживших, а не только те, которые успели раскрыться до конца голосований.
9. Синергия не является скрытым вторым голосованием: она работает только после завершения партии и не подсказывает игрокам во время выбора, кого выгонять.
10. Добавлены мягкие ограничения на вклад одной карточки/одного персонажа, чтобы набор из нескольких сильных характеристик не создавал «идеального» персонажа.

## Как запустить локально

```bash
python -m http.server 8000
```

Затем откройте:

http://localhost:8000

## Как играть бесплатно через интернет

### GitHub Pages

1. Создайте бесплатный аккаунт GitHub.
2. Создайте публичный репозиторий, например `bunker-lite`.
3. Загрузите туда `index.html`, `styles.css`, `app.js`, `README.md`.
4. В репозитории откройте **Settings → Pages**.
5. Выберите публикацию из ветки `main` и папки `/root`.
6. GitHub выдаст адрес вида `https://ВАШ_ЛОГИН.github.io/bunker-lite/`.
7. Создатель комнаты открывает сайт, создаёт комнату и отправляет друзьям ссылку.

PeerJS используется для соединения браузеров. Отдельный backend и база данных не нужны. Создатель комнаты должен держать вкладку открытой до конца игры.
